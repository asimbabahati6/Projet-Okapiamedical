# Guide Rapide - QR Code Réseaux Sociaux

## 🎯 Vue d'ensemble

Le QR code des réseaux sociaux d'Okapia Medical est maintenant intégré dans deux emplacements du site web pour faciliter l'accès à nos plateformes sociales.

---

## 📍 Où trouver le QR Code ?

### 1. Dans le Footer (Pied de page)

**Emplacement** : En bas de toutes les pages publiques du site

**Visibilité** :
- ✅ Ordinateur de bureau
- ✅ Tablette
- ✅ Mobile

Le QR code apparaît dans la 4ème colonne du footer, à côté des horaires d'ouverture.

```
┌─────────────────────────────────────────────┐
│  Logo    │  Contact  │  Horaires  │  QR Code │
└─────────────────────────────────────────────┘
```

### 2. Widget Flottant (Ordinateur uniquement)

**Emplacement** : Côté droit de l'écran, centré verticalement

**Visibilité** :
- ✅ Ordinateur de bureau uniquement
- ❌ Masqué sur tablette et mobile

**Comment l'utiliser** :
1. Cliquez sur l'onglet bleu sur le bord droit de l'écran
2. Le QR code se déploie
3. Scannez le code avec votre téléphone
4. Cliquez à nouveau pour le refermer

```
Rétracté:  ┌──┐        Déployé:  ┌────────────┐
           │◀ │                   │ ▶  Fermer  │
           └──┘                   │            │
                                  │  ┌──────┐  │
                                  │  │  QR  │  │
                                  │  └──────┘  │
                                  └────────────┘
```

---

## 📱 Comment scanner le QR Code ?

### Sur iOS (iPhone/iPad)

1. **Ouvrir l'appareil photo**
2. **Pointer vers le QR code**
3. **Cliquer sur la notification** qui apparaît en haut
4. Vous serez redirigé vers nos réseaux sociaux

### Sur Android

1. **Ouvrir l'appareil photo** ou une app de scan QR
2. **Pointer vers le QR code**
3. **Appuyer sur le lien** qui s'affiche
4. Vous serez redirigé vers nos réseaux sociaux

### Autres méthodes

- **WhatsApp** : Ouvrir > Paramètres > QR code > Scanner
- **Applications dédiées** : Google Lens, QR Code Reader

## ❓ Questions Fréquentes

### Le QR code fonctionne-t-il hors ligne ?

Non, vous devez avoir une connexion internet active pour accéder aux réseaux sociaux après le scan.

### Puis-je sauvegarder le QR code ?

Oui ! Faites un clic droit (ordinateur) ou appui long (mobile) sur l'image pour la télécharger.

### Le QR code expire-t-il ?

Non, ce QR code est permanent et restera toujours actif.

### Quels réseaux sociaux sont liés ?

Le QR code redirige vers la page principale de nos réseaux sociaux où vous pouvez choisir la plateforme de votre choix.

### Le widget flottant peut-il être désactivé ?

Le widget se ferme automatiquement en cliquant sur l'onglet. Il reste discret quand il est rétracté.

### Fonctionne-t-il sur tous les navigateurs ?

Oui ! Le QR code est compatible avec :
- ✅ Chrome
- ✅ Firefox
- ✅ Safari
- ✅ Edge
- ✅ Opera

## 🚨 Dépannage

### Le QR code ne s'affiche pas

**Solutions** :
1. Rafraîchir la page (F5 ou Ctrl+R)
2. Vider le cache du navigateur
3. Essayer un autre navigateur
4. Vérifier votre connexion internet

### Le widget flottant ne s'ouvre pas

**Solutions** :
1. Vérifiez que vous êtes sur ordinateur (pas mobile)
2. Cliquez bien sur l'onglet bleu
3. Désactivez les bloqueurs de contenu
4. Essayez en mode navigation privée

### Mon téléphone ne scanne pas le QR code

**Solutions** :
1. Assurez-vous que l'appareil photo a les permissions
2. Rapprochez-vous ou éloignez-vous du QR code
3. Améliorez l'éclairage de l'écran
4. Essayez une application de scan QR dédiée
5. Téléchargez l'image et scannez-la depuis la galerie
