## 3. STEP-BY-STEP REGISTRATION PROCESS

### Prerequisites
- Administrator or Hospital Admin account access
- Staff member contact information
- Professional credentials verified

### Process for Each Staff Member

#### Step 1: Create User Account
1. Navigate to **Settings** > **Staff Management**
2. Click **"Add Medical Staff"**
3. Fill in basic information:
   - Full Name
   - Email (professional)
   - Phone Number
   - Role: Select appropriate role (pharmacist/dentist/physical_therapist)
   - Department: Assign to specified department
4. Click **"Create Account"**

#### Step 2: Complete Professional Profile
1. Navigate to the newly created staff member profile
2. Fill in professional details:
   - License Number
   - Specialization
   - Years of Experience
   - Consultation Fee
   - Medical Order & Number
   - Qualifications (multiple entries)
   - Bio/Description
3. Set availability preferences:
   - Is Accepting Patients: ✓ Yes
   - Telemedicine Enabled: (as specified)
   - Can Work Nights: (as specified)
   - Can Work Weekends: (as specified)
4. Add professional contact:
   - Professional Email
   - Professional Phone
   - Languages Spoken
5. Save profile

#### Step 3: Verify Access
1. Confirm staff member can log in
2. Verify department assignment
3. Test appointment booking (if applicable)
4. Confirm telemedicine access (if enabled)
