## Accès Rapide aux Données

### Rendez-vous

**Module :** Staff → Rendez-vous
```sql
SELECT
  appointment_number,
  appointment_date,
  appointment_time,
  status,
  CASE
    WHEN telemedicine_notes IS NOT NULL THEN 'Télémédecine'
    ELSE 'Présentiel'
  END as type
FROM appointments
WHERE created_at >= CURRENT_DATE
ORDER BY appointment_date, appointment_time;
```

### Alertes de Stock

**Module :** Pharmacie → Stock
```sql
SELECT
  generic_name,
  brand_name,
  quantity_in_stock,
  reorder_level,
  (reorder_level - quantity_in_stock) as deficit,
  dosage_form,
  strength,
  expiry_date
FROM medications
WHERE quantity_in_stock < reorder_level
AND is_active = true
ORDER BY (reorder_level - quantity_in_stock) DESC;
```

### Brouillons

**Module :** Administration → Posts
```sql
SELECT
  title,
  excerpt,
  scheduled_publish_at,
  is_featured,
  reading_time,
  created_at
FROM posts
WHERE status = 'brouillon'
ORDER BY
  CASE
    WHEN scheduled_publish_at IS NOT NULL THEN scheduled_publish_at
    ELSE created_at
  END;
```
