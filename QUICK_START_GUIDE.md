## 📋 How to Use (3 Easy Steps)

### Step 1: Find Your Patient
1. Log in to staff dashboard
2. Go to "Documents Médicaux"
3. Use search box: Type patient name or number (e.g., "Marie" or "PAT-7005")
4. **OR** Click a document type button to filter

### Step 2: Select Document Type
- Each patient card shows colorful badges for their documents
- Click any badge to generate that document type
- Examples: Blue = Consultation, Green = Lab Results, Purple = Certificate

### Step 3: Create & Export
1. Generator opens with patient info pre-filled
2. Fill in the template sections
3. Click one of these:
   - **"Sauvegarder"** (Save to database)
   - **"Exporter en PDF"** (Download PDF)
   - **"Exporter en Word"** (Download DOCX)
4. Done! File downloads instantly

## 📄 Section Types Explained

### 📝 Text Section
- For paragraphs, descriptions, notes
- Just type your content

### 📋 List Section
- For bullet points, medications, instructions
- Enter one item per line

### 📊 Table Section
- For lab results, vital signs, data
- Click "+ Colonne" to add columns
- Click "+ Ligne" to add rows
