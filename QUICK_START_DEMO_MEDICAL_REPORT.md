# Guide Rapide - Rapport d'Activité Médicale

## 🚀 Démarrage Rapide en 3 Étapes

### Étape 1 : Générer les Données (10 secondes)

1. Ouvrir **OKAPIA MEDICAL**
2. Se connecter en tant qu'administrateur
3. Aller dans **"Rapports Financiers"** (menu latéral)
4. En haut de la page, voir l'encadré violet **"Données de Démonstration"**
5. Cliquer sur **"Générer les Données"**
6. ✅ Confirmation : 40 patients + 150 factures créés

---

### Étape 2 : Générer le Rapport PDF (15 secondes)

1. Une fois les données créées, le bouton change automatiquement
2. Cliquer sur **"Générer le Rapport PDF"**
3. Attendre quelques secondes
4. 📥 Le PDF se télécharge : `rapport-activite-medicale-jan-juin-2024.pdf`

---

### Étape 3 : Consulter le Rapport

1. Ouvrir le PDF téléchargé
2. Lire les 8-10 pages :
   - ✅ Page 1 : Couverture professionnelle
   - ✅ Page 2 : Résumé exécutif avec chiffres clés
   - ✅ Pages 3-4 : Analyse mensuelle et trimestrielle
   - ✅ Page 5 : Tableaux récapitulatifs détaillés
   - ✅ Page 6 : Analyse des tendances
   - ✅ Page 7 : Recommandations stratégiques
   - ✅ Page 8 : Annexes et méthodologie

## 📞 Support

- Réessayer la génération

**PDF non téléchargé :**
- Vérifier les autorisations du navigateur
- Désactiver le bloqueur de pop-ups
- Essayer un autre navigateur

- Supprimer et régénérer

- Contacter le support technique
