## COMMON WORKFLOWS

### Workflow 1: Creating a Task

1. Go to **Tâches** page
2. Click **"Nouvelle tâche"** (New task)
3. Enter task details:
   - Title
   - Description
   - Type (HR, Finance, Operations, etc.)
   - Priority
   - Due date
4. Assign to staff member
5. Click **Save**

### Workflow 2: Handling Maintenance Request

1. Go to **Installations** page
2. Click **"Nouvelle demande"** (New request)
3. Enter details:
   - Location
   - Description
   - Priority
   - Type (repair, maintenance, inspection, etc.)
4. Click **Save**
5. System alerts operations team
6. Operations manager assigns to staff
7. Staff updates status as work progresses
8. Mark **Completed** when done

### Workflow 3: Managing Vendor Contract

1. Go to **Fournisseurs** page
2. View expiring contracts (highlighted in yellow)
3. Click **"Renouveler"** (Renew) button
4. Update contract details:
   - New end date
   - Updated value
   - New terms
5. Click **Save**
6. System resets renewal reminder

### Workflow 4: Creating Policy

1. Go to **Politiques** page
2. Click **"Nouvelle politique"** (New policy)
3. Enter policy details:
   - Title
   - Policy number (unique)
   - Category
   - Description
   - Effective date
   - Review date
4. Status starts as **Draft**
5. Director reviews and approves
6. Status changes to **Active**

## FREQUENTLY ASKED QUESTIONS

**Q: Can I delete a task?**
A: No, but you can cancel it. This maintains audit trail.

**Q: How do I know when contracts are expiring?**
A: The Fournisseurs page highlights contracts expiring within 30 days in yellow.

**Q: Can I export data?**
A: Export functionality coming in Phase 2.

**Q: How do I assign a task to someone?**
A: Select the staff member from the "Assigned to" dropdown when creating the task.

**Q: Can I attach files to tasks/requests?**
A: Yes, use the attachments field (currently supports document URLs).

**Q: How are priorities determined?**
A: Set by the task/request creator based on urgency and impact.

**Q: Can I see all my assigned tasks?**
A: Yes, the Tâches page shows all your assigned tasks when you're logged in.

**Q: How do I rate vendor performance?**
A: Edit the vendor contract and update the performance rating (1-5 stars).

## BEST PRACTICES

### Task Management
- Set realistic due dates
- Update task status regularly
- Add clear descriptions
- Use appropriate priority levels
- Review completed tasks weekly

### Maintenance Requests
- Be specific about location
- Include detailed description
- Add photos if possible
- Set correct priority
- Follow up on completion

### Contract Management
- Review contracts 60 days before expiration
- Update performance ratings quarterly
- Keep vendor contact info current
- Document all amendments
- Archive expired contracts

### Policy Management
- Review policies annually
- Keep version history
- Get proper approvals
- Communicate changes to staff
- Archive outdated versions

## GLOSSARY

**Administrative Staff** - Personnel working in the Administration Department

**Division** - One of four areas: HR, Finance, Operations, IT

**Task Type** - Category of task (hr, finance, operations, compliance, reporting)

**Priority** - Urgency level (low, medium, high, urgent, emergency)

**Status** - Current state (pending, in_progress, completed, cancelled)

**RLS** - Row Level Security (data access control)

**KPI** - Key Performance Indicator (metric to measure success)

**Contract Type** - Category of vendor contract (service, supply, maintenance, consulting, equipment)

**Access Level** - Permission level (full, division_only, limited)
