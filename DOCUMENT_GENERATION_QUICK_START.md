# Guide de Démarrage Rapide - Génération de Documents

## 🚀 Accès en 30 Secondes

### 1. Se Connecter
- Compte **Médecin**, **Infirmière** ou **Administrateur**

### 2. Naviguer
- Sidebar → **"Documents Médicaux"** 📄

### 3. Utiliser
- Tableau récapitulatif visible en haut de page
- 8 types de documents avec patients assignés
- Boutons [PDF] et [Word] pour chaque ligne

---

## ⚡ Exports Rapides

### Export PDF (1 clic)

```
1. Trouver le type de document dans le tableau
2. Cliquer bouton rouge [PDF]
3. Fichier téléchargé automatiquement
4. Ouvrir avec lecteur PDF
```

**Temps** : 2 secondes

### Export Word (1 clic)

```
1. Trouver le type de document dans le tableau
2. Cliquer bouton bleu [Word]
3. Fichier .docx téléchargé
4. Ouvrir avec Microsoft Word
```

**Temps** : 2 secondes

---

## 💥 Génération en Masse

### Pour générer plusieurs documents

```
1. Clic bouton vert "Génération en Masse"
2. Cocher les types souhaités (ou "Tout sélectionner")
3. Choisir format: PDF, Word, ou Les deux
4. Clic "Générer (X)" où X = nombre de fichiers
5. Attendre la progression
6. Tous les fichiers téléchargés automatiquement
```

**Exemple** : 8 documents en PDF + Word = 16 fichiers en 30 secondes

**R** : Oui, en exportant en Word. Le PDF est non modifiable.
